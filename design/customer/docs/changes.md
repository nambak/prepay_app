# 원본에서 달라진 점

원본: 피그마 파일 `☆고객용-APP_Design (복사)` (앱 화면 약 330개, 상태 변형 포함)
리디자인: 사용 흐름과 정보 구조는 유지하고 화면 구성, 색, 컴포넌트를 새로 만듦 (대표 화면 76개)

## 1. 디자인

| 원본 | 리디자인 |
|---|---|
| 빨간 헤더·버튼·토글·금액이 한 화면에 몰림 | 흰 바탕 + 무채색, 빨강은 주요 버튼과 할인율에만 |
| 가게 카드에 색 배지 3개(할인율·좋아요·거리) + 해시태그 줄 | 할인율 배지 하나, 거리·찜 수는 회색 글자 |
| 홈에 같은 가로 스크롤이 6번 반복, 세로 3,807px | 타일 · 순위 목록 · 브랜드 · 신규 목록으로 섹션마다 형태를 달리, 세로 2,000px |
| 내단골 카드에 차감·충전·공유 버튼, 머니 내역, 공유 토글이 모두 펼쳐짐 | 잔액 + 쓰기 버튼만 보이고 상세는 펼쳐서 확인 |
| 툴팁 말풍선 30여 개 | ⓘ 버튼 + 용어 설명 시트 |
| 아이디 @ 이메일 도메인 분리 입력, 1px 테두리 상자와 외곽선 버튼 | 이메일 한 칸 입력, 채워진 입력창, 하단 고정 버튼 |
| 하단 탭 가운데 빨간 원형 버튼 | 같은 자리의 '내 가게' 지갑 탭, 다른 탭과 같은 무게 |
| 단계 탭(step1~4) | 상단 진행 막대(1/3) |
| '내역 없음' 화면 20여 개 | 빈 화면 패턴 하나 (`components/patterns.html`) |
| 서체 Pretendard | 시안은 Noto Sans KR(캔버스 제약), 구현은 Pretendard 권장 |

## 2. 상표를 피하려고 바꾼 이름

| 원본 | 바꾼 이름 |

## 5. 확인이 필요한 점

- 새 이름(즐겨찾는 가게, 포인트, 그룹)이 상표로 등록돼 있는지 키프리스(KIPRIS)에서 확인이 필요해요.
- '즐겨찾는 가게'(포인트가 있는 가게)와 '찜한 가게'(관심만 둔 가게)는 뜻이 비슷해 헷갈릴 수 있어요. 탭 이름을 더 구분할지 검토가 필요해요.
- 원본의 38-1~38-4 가게정보 오류신고, 40-1 이용약관은 따로 그리지 않았어요(`docs/screen-list.md` 참고).
