# prepay-app

동네 가게 선결제 고객 앱의 리디자인 시안이에요.

- **보기**: `index.html`을 브라우저로 열어요. 서버나 빌드는 필요 없어요.
- **구성**: 대표 화면 76개(`screens/`), 공통 컴포넌트(`components/`), 디자인 토큰(`tokens/`), 문서(`docs/`)
- **문서**: 디자인 기준은 `docs/design-spec.md`, 화면 목록과 원본 대응은 `docs/screen-list.md`, 원본과 달라진 점은 `docs/changes.md`
- **클로드 코드**: 작업 규칙은 `CLAUDE.md`에 있어요.
