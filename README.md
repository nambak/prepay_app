# prepay-app

동네 가게 선결제 서비스예요. 고객 앱 리디자인 시안, Flutter 고객 앱, Laravel 서버가 함께 있어요.

- **시안 보기**: `design/customer/index.html`을 브라우저로 열어요. 서버나 빌드는 필요 없어요.
- **시안 구성**: `design/customer/` 안에 대표 화면 76개(`screens/`), 공통 컴포넌트(`components/`), 디자인 토큰(`tokens/`), 문서(`docs/`)가 있어요.
- **문서**: 디자인 기준은 `design/customer/docs/design-spec.md`, 화면 목록과 원본 대응은 `design/customer/docs/screen-list.md`, 원본과 달라진 점은 `design/customer/docs/changes.md`
- **고객 앱**: `customer_app/` (Flutter)
- **서버**: `server/` (Laravel)
- **클로드 코드**: 작업 규칙은 `CLAUDE.md`에 있어요.
